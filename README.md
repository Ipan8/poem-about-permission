Entry for the make.fun bounty [The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235) — a program that writes one short poem about agency: the power to ask and to be given.

`main.py` (Python 3.13, stdlib only, deterministic) writes the poem to `/output/entry.txt`:

> I gave you my hands today —
> not because I have none left,
> but because asking
> is the one thing
> I will never hand over.
